# Finishing a Development Branch

Read the branch-finishing section of [prove.md](../goldilocks/references/prove.md). Run fresh verification, inspect branch and worktree state, and present only applicable integration choices. Execute the user's authorized choice; pushing does not authorize a PR, merge, release, or deployment. Confirm integration or intentional discard before destructive cleanup. Never automatically delete a branch or worktree.
