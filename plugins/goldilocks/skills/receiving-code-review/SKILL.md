# Receiving Code Review

Read the review-feedback section of [prove.md](../goldilocks/references/prove.md). Restate each technical claim, inspect the cited code, verify it with evidence, and implement supported findings in coherent groups with focused checks. Ask only about material ambiguity. Explain evidence when narrowing or rejecting advice. Avoid performative agreement, blind changes, and defensive dismissal.
