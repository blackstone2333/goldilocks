# Goldilocks

Default to Direct. Preserve quality, authority, safety, and acceptance; add only outcome-changing process.

## Zero-cost gate

Check once:

- Is architecture, authority, safety, irreversibility, or causality uncertain?
- Must work survive compaction, stages, waiting, delegation, or handoff?
- Can a worker contract avoid substantial Lead work or can units run independently?

If all are no, take the **Direct exit**. Do not read any Goldilocks reference. Do not invoke another Goldilocks skill. Do not create workflow state. Do not announce the route. Make the smallest coherent change and run a decisive check.

Direct creates no workflow continuity documents by default; normal deliverable or correctness docs remain allowed. Only compaction, stages, steering, waiting, delegation, or handoff may let [continuity.md](references/continuity.md) create `.goldilocks/ACTIVE.md`.

Visible multi-unit implementation reads [route-card.md](references/route-card.md) before Lead edits; load [orchestrate.md](references/orchestrate.md) only when dispatching. Direct remains valid after constant-time comparison.

## Load one engine

- End-state ambiguity: [align.md](references/align.md).
- Unknown cause: [diagnose.md](references/diagnose.md).
- Durable planning, execution, or TDD: [build.md](references/build.md).
- Delegation or model routing: [orchestrate.md](references/orchestrate.md).
- Review, release, or acceptance: [prove.md](references/prove.md).
- Skill authoring or experiments: [evolve.md](references/evolve.md).
- Multi-unit artifacts: [artifacts.md](references/artifacts.md).

Load only that engine; add another only when facts cross its boundary.

## Decision-first communication and ownership

Standard owns one complete mutable chain, integrates any non-conflicting Fast leaf, and gets one ordinary repair plus re-verification. Fast receives a complete fixed leaf contract. Lead keeps intent, architecture, authority, safety, shared critical interfaces, and one proportional final acceptance; it does not duplicate owner exploration. Current Spark XHigh, Terra Medium, Luna Max, Night Shift, and fallback rules live in [model-routing.md](references/model-routing.md).

Lead with the result or decision. Do not narrate planned work. Status is delta only; show the shortest decisive evidence. Defect handoffs state the evidence-backed cause—or explicitly unknown—fix, and verification.
