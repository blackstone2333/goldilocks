# Goldilocks

Default Direct; preserve quality, authority, safety, acceptance. Add only outcome-changing process.

## Zero-cost gate

Check architecture, authority, safety, irreversibility, causality, continuity, and useful decomposition.

If clear, take the **Direct exit**. Do not read any Goldilocks reference. Do not invoke another Goldilocks skill. Create no workflow state. Make the smallest change, check decisively, and append one localized Direct receipt. Usage is host-side and fail-silent: on-demand unless explicitly automatic.

Direct creates no workflow continuity documents by default; normal deliverable or correctness docs remain allowed. Compaction, stages, steering, waiting, delegation, or handoff may let [continuity.md](references/continuity.md) create `.goldilocks/ACTIVE.md`. Pure conversation omits receipt and Usage.

If Direct later reveals uncertainty, unknown cause, persistence, or independent ready units, leave Direct and load only the matching engine. Visible multi-unit implementation reads [route-card.md](references/route-card.md) for one constant-time comparison only when multiple units become real, [orchestrate.md](references/orchestrate.md) only when dispatching, and [continuity.md](references/continuity.md) only when persistence is required. The root still supplies the localized receipt.

## Load one engine

- End-state ambiguity: [align.md](references/align.md).
- Unknown cause: [diagnose.md](references/diagnose.md).
- Durable planning, execution, or TDD: [build.md](references/build.md).
- Delegation or model routing: [orchestrate.md](references/orchestrate.md).
- Review, release, or acceptance: [prove.md](references/prove.md).
- Skill authoring or experiments: [evolve.md](references/evolve.md).
- Multi-unit artifacts: [artifacts.md](references/artifacts.md).

Load only that engine; add another only when facts cross its boundary.

## Decision-first communication

Standard owns one complete mutable chain and gets one ordinary repair plus re-verification. Fast receives a complete fixed leaf contract. Lead keeps intent, architecture, authority, safety, shared interfaces, and one proportional final acceptance; it does not duplicate owner exploration. Models and fallbacks live in [model-routing.md](references/model-routing.md).

Lead with the result. Do not narrate planned work. Status is delta only; show shortest decisive evidence. Defects add the evidence-backed cause—or explicitly unknown—fix and verification; expand when asked.
