# Requesting Code Review

Read the review section of [prove.md](../goldilocks/references/prove.md). Give the reviewer the end state, constraints, acceptance, diff or commit range, and checks run. Request prioritized findings with file evidence, not generic approval. Use self-review for trivial Direct work, a focused independent pass for significant or orchestrated work, and independent review for Critical changes.
