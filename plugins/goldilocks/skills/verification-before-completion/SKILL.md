# Verification Before Completion

Read [prove.md](../goldilocks/references/prove.md). Identify what proves each claim, run the relevant command or real-runtime check fresh, read the full result, and inspect the final diff and status. If evidence is unavailable or forbidden, name the exact unverified claim. Never substitute confidence, old results, review prose, or an agent report for current evidence.
