# Subagent-Driven Development

Read [orchestrate.md](../goldilocks/references/orchestrate.md), then [build.md](../goldilocks/references/build.md) and [prove.md](../goldilocks/references/prove.md). Delegate only bounded units with stable acceptance; route mechanical work to Fast and judgment to Lead. Review and re-review actual output, while the coordinator owns interfaces and final integration. Stay inline for a single coherent task or when orchestration cost is not positive.
