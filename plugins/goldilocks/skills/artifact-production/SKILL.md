# Artifact Production

Read [artifacts.md](../goldilocks/references/artifacts.md). Goldilocks organizes production; an available specialist skill handles the format. Do not copy specialist instructions.

Load only the matching profile: presentations use [presentations.md](references/presentations.md). Send one small inseparable deliverable directly to its specialist and verify it.

Otherwise freeze the global and unit contracts, keep units independently replaceable, batch safely, and name one integration owner. Review units locally, repair only failures, then verify the integrated artifact globally.
