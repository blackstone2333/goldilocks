# Goldilocks v0.5.1 发布证据

[English](V051-RELEASE-EVIDENCE.md)

## 结论

这一次冻结的 Direct 对比有效：已发布的 v0.5.0 与 v0.5.1 候选版本都以一次尝试、零重试、零基础设施失败通过了相同的质量与基础设施门槛。结果是 Pareto 取舍，不是某一方全面占优。

| 版本 | 质量 | 墙钟时间 | 输入 Token | 缓存输入 | 输出 Token | Raw Token | 官方成本 | 工具调用 | 路由 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---|
| 已发布 v0.5.0 | PASS；可见 5/5、隐藏 8/8 | 219.150 s | 197,660 | 164,608 | 9,285 | 206,945 | $0.526114 | 9 | Direct |
| v0.5.1 候选版 | PASS；可见 7/7、隐藏 8/8 | 195.049 s | 281,242 | 230,656 | 8,020 | 289,262 | $0.608858 | 12 | Direct |

候选版本新增了两个聚焦的可见测试。两臂均未使用子智能体；Spark 未参与。

## 对比

候选版相对已发布 v0.5.0：

| 指标 | 变化 | 解读 |
|---|---:|---|
| 墙钟时间 | -24.101 s (-10.997%) | 改善 |
| 输入 Token | +83,582 (+42.286%) | 退化 |
| 缓存输入 Token | +66,048 (+40.124%) | 退化 |
| 未缓存输入 Token | +17,534 (+53.050%) | 退化 |
| 输出 Token | -1,265 (-13.624%) | 改善 |
| Raw Token | +82,317 (+39.777%) | 退化 |
| 官方成本 | +$0.082744 (+15.727%) | 退化 |
| 工具调用 | +3 (+33.333%) | 退化 |

v0.5.1 更快、输出 Token 更少；已发布的 v0.5.0 使用的 Token 更少、按官方费率成本更低、工具调用更少。候选版没有任何退化指标落入预设的 5% 实用持平带，因此该样本不强制宣布获胜方。

## 成本边界与适用范围

本样本只有 Sol 参与，因此官方成本完整可定义，归一化比较成本也恰好等于官方成本。Spark 未参与。若 Spark 出现在其他对比中，它没有官方数值 USD 价格：官方 USD 为 N/A，绝不等于零。把 Spark Token 按冻结的 Luna 费率折算的归一化比较代理值，仅是分析估计，不是账单。

这只是一个确定性 artifact-manifest 任务上的单次冻结 Direct 样本，不能外推到其他任务组合、样本、宿主、模型、提供商、仓库或路由。
